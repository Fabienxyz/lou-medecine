## Difficulties encountered

### 1. FIL B typographic apostrophes (U+2019)

The edition-2022 chapter uses curly apostrophes (`'`) throughout (e.g. `l'aspirine`, `d'action`). Inventory anchor quotes must match the source verbatim after `normalizeWhitespace`; straight ASCII apostrophes cause `quote not found` validation failures.

**Resolution**: Ran `build/fix-anchors.mjs` (chapter-local helper) to extract exact substrings from source with flexible apostrophe matching, then hand-fixed six remaining ambiguous/duplicate quotes.

### 2. Section heading markers vs. source headings

Subsection markers in `source.meta.yaml` must match the source file exactly, including:
- `### B Mode d'action – Pharmacologie (cf. tableau 22.4)` for II.B (curly apostrophe)
- `### A Accidents liés à l'administration d'héparines` for VI.A

Incorrect markers break section scoping and can produce duplicate-match anchor errors.

### 3. Non-unique short anchors

Several short phrases appear multiple times in scope (e.g. `CI si ClCr < 30 mL/min` in table rows, `syndrome coronarien aigu`, `1 à 2 mg de vitamine K` in table 22.14). Anchors were lengthened to unique verbatim spans.

### 4. Line-wrap in source

Some sentences span two lines (e.g. aspirin posology line 73–74). Anchors must not cross line breaks unless the full normalized span is unique; shorter in-line quotes were preferred.

### 5. Semantic grounding bootstrap

Two bridging claims (`cb-story-pipeline`, `cb-overview-pipeline`) require bootstrap verdicts in `chapter.package.yaml` — same pattern as Item 234 OAP slice.
