# Vue d'ensemble

L'insuffisance cardiaque repose sur un mécanisme unique :

1. Le cœur pompe moins bien.
2. Le débit cardiaque diminue.
3. Le cerveau et les reins activent des mécanismes de compensation.
4. Ces compensations deviennent progressivement délétères.
5. Le cœur se dégrade encore.
6. Apparaissent alors les symptômes :
   - dyspnée
   - fatigue
   - œdèmes

Le schéma ci-dessous résume toute cette cascade.
