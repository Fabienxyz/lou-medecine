# AI-Native Knowledge Repository

Ce repository est un **Knowledge Repository** : il centralise la connaissance d'un projet (vision, produit, architecture, décisions) pour que les humains et les agents IA puissent s'y appuyer.

Il ne contient **pas de code applicatif**. Pas de dépendances, pas de build, pas de déploiement ici.

Le code vivra dans un **repository séparé**, lié à celui-ci par la documentation et le contexte partagé.

Pour commencer, ouvrez [START_HERE.md](START_HERE.md).
