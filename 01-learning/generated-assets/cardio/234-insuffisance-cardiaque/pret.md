# Suis-je prêt ?

Tu dois être capable d'expliquer :

- Pourquoi le débit cardiaque diminue.
- Pourquoi le cerveau active le système sympathique.
- Pourquoi le rein active le SRAA.
- Pourquoi la dyspnée apparaît.
- Pourquoi les œdèmes apparaissent.
- Pourquoi les compensations aggravent finalement la maladie.

Si tu peux raconter cette histoire sans regarder le cours, tu maîtrises la logique du chapitre.
